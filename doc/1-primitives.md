### variable `move_bytes_variant`

```c++

```

The move_bytes variant of this CPU. Starts on a resolver that runs cpuid on the first call, stores the variant here and forwards to it. x86-64: SSE2 or AVX2; each copies up to 8 vectors with overlapping loads and stores, more with an aligned 4-vector loop, rep movsb from 8 KiB with ERMS and non-temporal stores from half the last-level cache. ## `utility/initializer_list.hpp`

The one std name braced lists need. The compiler turns `{1, 2, 3}` into a std::initializer_list\<E> on its own, as a pointer and a length written straight into the object, so the class must be called that and have that layout (libstdc++'s and libc++'s). Defined here and nowhere else; ca code spells it ca::initializer_list. When a standard library's <initializer_list> came first, its definition is used; after this one, the libstdc++ and libc++ guards are set so theirs adds nothing.

### class `initializer_list`

```c++
template <typename E>
class initializer_list final;
```

Read-only view of the array behind a braced list; lives as long as the full expression that made it (or the variable it initializes). Built by the compiler only.

### function `initializer_list::size`

```c++
[[nodiscard]] constexpr auto size(void) const noexcept -> ca::usz;
```

Number of elements.

### function `initializer_list::data`

```c++
[[nodiscard]] constexpr auto data(void) const noexcept -> const E*;
```

The elements; ca::is_contiguous, so it converts to a borrowed_slice\<const E>.

### alias `initializer_list`

```c++
template <typename E>
using initializer_list = std::initializer_list<E>;
```

std::initializer_list\<E>: what `{a, b, c}` becomes in a range-for or as an argument.
