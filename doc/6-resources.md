## `fs/descriptor.hpp`

### class `descriptor`

```c++
class descriptor final;
```

An owned POSIX file descriptor whose flags are typed options, combined at compile time: `descriptor::open(p, fs::writable | fs::create | fs::cloexec)`, `d |= fs::nonblock`, `d &= ~fs::append`. Each option knows its domain (open-time, FD_* or file status flags); set/clear/test issue only the fcntl calls their domains need and keep every unrelated bit. Contradictions (exclusive without create, truncate without writable, open-time options after open) fail to compile. Close with destroy(); the destructor is a failsafe that closes silently.

## `io/reader.hpp`

Buffered input from a file descriptor.

Performance:

- Layout: four pointers (buffer begin, read cursor, end of data, end of buffer), the fd and a tied writer pointer; 48 bytes on 64-bit. The buffer is borrowed, never allocated. Trivially destructible: nothing to flush on input.
- read() serving buffered bytes is one compare and a memcpy; reads at least as large as the buffer go straight to the fd, no copy.
- fill()/consume() and read_until() lend the buffer: lines and tokens are parsed in place. read_until scans each byte once (memchr), across refills; it moves the unread tail to the front only when the buffer must take more.
- One read call per refill, sized to the free space.

Baseline stdio (getline, fread); a file of 1e6 lines of about 45 bytes: bench/read.cpp on Intel Core i7-10750H, -O2, min of 9 runs: user cycles relative to the baseline.

| Case | clang 18 | gcc 13 | Notes |
|---|---|---|---|
| 1e6 lines in place, read_until | 0.63x | 0.64x | std: getline |
| 1e6 lines copied, read_line | 0.88x | 0.93x | std: getline |
| 4 KiB chunks, read | 0.55x | 0.53x | std: fread |

Buffered input and output over file descriptors: sockets, terminals, pipe pairs.

Performance:

## `io/writer.hpp`

Buffered output to a file descriptor.

Performance:

- Layout: three pointers (buffer begin, fill cursor, end), the fd, the policy and the sticky error; 40 bytes on 64-bit. The buffer is borrowed, never allocated: the caller (or the per-thread standard writers) owns it.
- Formatting writes straight into the buffer through window()/drain()/settle(): no staging copy. write() is one bounds check and a memcpy while the bytes fit.
- Slow paths (writing out, writes larger than the buffer) are out of line and take the fd and pointers, never `this`, so callers keep the cursor in a register.
- Writes larger than the whole buffer bypass it: pending bytes first, then the data directly, two write calls and no copy.
- line policy scans only the bytes of the current message for '\n' (memchr).
- A writer without a buffer (unbuffered(fd)) has an empty window: print stages each message on its stack (1 KiB) and writes it with one call.
- A failed write-out moves the bytes not written to the front of the buffer (memmove), error path only.

### class `writer`

```c++
class writer final;
```

Writer over a file descriptor it does not own, buffering into memory the caller provides, with a policy (ca::io::buffering). Each call returns its own error, and the first one since the last check is kept, sticky: error() peeks, clear_error() forgets it once handled, flush() returns and clears it. When writing out fails, the bytes not written stay pending, never retried behind the caller's back: flush() retries them, discard() drops them; a message still being formatted is dropped whole unless part of it already went out. Cleanup is flush(); the destructor is a failsafe that writes out pending bytes silently. Not thread-safe: one writer per thread (ca::io::out() is).

```c++
[[nodiscard]] auto write(const ca::span<const ca::byte> data) noexcept -> ca::result<void>;
```

Appends data, then applies the policy to it; fails when that writes out and the write fails, data then pending. Data that does not fit is refused when writing out the pending bytes fails. Data larger than the buffer goes out directly: on failure, what was not written is lost.

### function `writer::write_pending`

```c++
[[nodiscard]] auto write_pending(void) noexcept -> ca::result<void>;
```

Writes pending bytes out; this write-out's error, also kept sticky. What a reader tied to this writer calls before it blocks.

### function `writer::flush`

```c++
[[nodiscard]] auto flush(void) noexcept -> ca::result<void>;
```

Writes pending bytes out, then returns the sticky error (this write-out's when it is the first) and clears it.

### function `writer::clear_error`

```c++
constexpr auto clear_error(void) noexcept -> void;
```

Forgets the sticky error, once handled, so flush() does not report it again.

### function `writer::discard`

```c++
constexpr auto discard(void) noexcept -> void;
```

Drops the pending bytes, unwritten.

### function `writer::set_buffer`

```c++
[[nodiscard]] auto set_buffer(const ca::span<char> buffer) noexcept -> ca::result<void>;
```

Writes pending bytes out, then buffers into buffer instead (empty: unbuffered); bytes a failed write-out kept move along when they fit, else are lost. Returns the write-out's error. The old buffer is free once this returns.

### function `writer::set_buffering`

```c++
[[nodiscard]] auto set_buffering(const ca::io::buffering mode) noexcept -> ca::result<void>;
```

Changes the policy; none writes pending bytes out now, returning that error.

### function `writer::window`

```c++
[[nodiscard]] constexpr auto window(void) const noexcept -> ca::span<char>;
```

Free buffer space; empty for an unbuffered writer. See is_windowed_writer.

### function `writer::drain`

```c++
[[nodiscard]] auto drain(char* const at) noexcept -> ca::result<ca::span<char>>;
```

Writes the buffer out up to at; lends it again whole. On failure the message is dropped and the earlier bytes not written stay pending.

### function `writer::settle`

```c++
[[nodiscard]] auto settle(char* const at) noexcept -> ca::result<void>;
```

Ends a message at at, then applies the policy to it; fails as write.

### function `writer::_emit`

```c++
[[nodiscard]] static auto _emit(int fd, const char*& from, const char* to) noexcept -> ca::error;
```

Writes [from, to) to fd, from advancing past what went out; the error, ok on success.

### function `writer::_keep`

```c++
auto _keep(const char* const from) noexcept -> void;
```

Pending becomes [from, _at), moved to the front.

## `print/flush.hpp`

### function `flush`

```c++
[[nodiscard]] inline auto flush(void) noexcept -> ca::result<void>;
```

Writes out what print and printf buffered in this thread's stdout; the first error since the last flush, if any. The explicit cleanup of stdout: exit's failsafe ignores errors.

## `print/print.hpp`

### function `print`

```c++
template <typename... Args>
requires (ca::is_displayable<Args> && ...)
[[nodiscard]] auto print(const ca::format_string<ca::type_identity<Args>...> format, const Args&... args) noexcept -> ca::result<ca::usz>;
```

Prints args, `{}` syntax (see format_string), checked at compile time: `ca::print("{} items in {}\n", n, path)` goes to ca::io::out(), this thread's buffered stdout; `ca::print(writer, ...)` to any writer: ca::io::err() or ca::io::writer::unbuffered(fd) write at once. Each message reaches the writer whole. Returns the message's size in bytes (buffered: once the writer holds it), or its error; the writer also keeps the error sticky, for a final check with its flush() (ca::flush() for stdout), clear_error() once handled.

## `print/print_trace.hpp`

### function `print_trace`

```c++
[[nodiscard]] inline auto print_trace(const ca::error error) noexcept -> ca::result<ca::usz>;
```

Prints error and its thread trace (see ca::trace::record), then a newline: `ca::print_trace(r.error())` to ca::io::err(), `ca::print_trace(writer, e)` to any writer. An error without the current trace prints its message only. A ca::report prints with ca::print and `{}`. Errors as print.

## `print/printf.hpp`

### function `printf`

```c++
template <typename... Args>
requires (ca::is_displayable<Args> && ...)
[[nodiscard]] auto printf(const ca::printf_string<ca::type_identity<Args>...> format, const Args&... args) noexcept -> ca::result<ca::usz>;
```

print with C % syntax (see printf_string), typed and checked at compile time, no varargs: `ca::printf("%-8s|%5.2f\n", name, ratio)`. Same targets, buffering and errors (per call and sticky) as print.
