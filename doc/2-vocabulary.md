## `uncertain.hpp`

### class `uncertain`

```c++
template <typename D, typename T>
class uncertain;
```

CRTP base of containers that may lack their value (optional, result). A container starts unchecked. An observer (holds, bool, ok, has_value) checks it and makes it a realized value; any change of contents unchecks it. In debug builds (ca_debug) unchecked access fails: at compile time when the optimizer proves it (-O1 and up) or in constant evaluation, otherwise by a trap. Release builds keep no flag.

D derives uncertain<D, T>, befriends it, and privately provides: _realizable() const -> bool; _realized_ref() &, const&, && -> realized\<T>&, const&, &&; _absent(F& f) -> f(what stands in for the value). Observers report through _observe(bool); every change of contents calls _unobserve().

One message: window() lends free space, a span of chars (empty: none to lend); when the writer fills it, drain(at) takes [window start, at) and lends fresh space, never empty; on failure the message is over, rolled back as far as nothing of it left the writer, and settle is not called. settle(at) ends the message at at and applies the buffering policy; it fails when writing out does. Errors are also recorded, sticky.

## `io/is_writer.hpp`

### concept `is_writer`

```c++
template <typename S>
concept is_writer = requires (S& writer, const S& view, const ca::span<const ca::byte> bytes) {
    { writer.write(bytes) } -> ca::is_same<ca::result<void>>;
    { writer.flush() } -> ca::is_same<ca::result<void>>;
    { view.error() } -> ca::is_same<ca::error>;
    writer.clear_error();
};
```

A byte sink print and printf can target. Errors are reported twice: each call returns its own (write(bytes) -> result\<void>: stop early when output is impossible), and the writer keeps the first one since the last check, sticky (one check point for deferred or scattered writes). error() peeks at it; clear_error() forgets it once handled, so it is not reported again; flush() writes out what is pending, then returns and clears it. Text passes as bytes: write(ca::sv::str{...}).
